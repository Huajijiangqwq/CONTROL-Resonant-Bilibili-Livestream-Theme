## 没有打包

开发期间用到的其他游戏截图与完整录像、上表以外的历史参考图、用户的歌曲封面、录制频谱与私人素材，未随本包分发。上表列出的原主题显示素材已恢复。

官方双 Logo 保留原有左右排版；FBC 插入、礼物物证图、舰队碎光与演示背景使用原主题素材。编辑器、参数、排版与主要动画时序保留。替代 SVG 仅保留为可选素材，不再替换默认外观。

## 自行导入

可以通过编辑器导入自己拥有或获准使用的图片 / 视频，再导出个人主题。素材会嵌入主题，因此分享 JSON 也属于分享其素材。重新发布主题前，应自行确认这些素材的许可；项目 MIT 不覆盖它们。

Control、CONTROL Resonant、Alan Wake、Bilibili、OBS 等名称用于说明灵感或兼容性，并非本项目拥有的商标。字体许可不改变这些名称的商标权。
