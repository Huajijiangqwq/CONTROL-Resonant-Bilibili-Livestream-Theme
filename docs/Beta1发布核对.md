# Beta 1 发布核对

核对日期：2026-09-21。发布目标为 Windows 本地源码版，版本 `0.1.0-beta.1`。

## 已执行

- 在独立端口组启动全部服务，保留原来的主题页面服务。
- 在包含中文与空格的新目录中解压，从源码首次编译 Windows 音频组件，启动四个服务。
- 验证重复启动不会重复开服务；端口被占用时明确失败；修正多个 Node.js 路径导致启动失败的问题。
- 验证停止命令只停止本副本；原主题页面服务仍可访问。
- 检查 141 个源文件、257 个运行资源引用：语法与资源路径检查通过。
- 7 组 Node.js 自动测试通过，其中 OBS 实时同步回归覆盖 17 项断言：来源创建、多实例、几何更新、删除、暂停、恢复、冲突写入保护、重新启动、保持浏览器地址与不操作录制 / 直播。
- 浏览器检查主题编辑器、独立弹幕编辑器、四类消息预览、音乐合成演示及主题发布 URL。
- ZIP 文件逐项校验 CRC 与 SHA-256；排除个人设置、绑定、发布快照、日志、编译产物、历史试验页与开发机依赖路径。

## 验证范围

这轮没有连接真实 Bilibili 账户或操控实际 OBS 直播场景；音频验证包括源码编译与音源枚举，不宣称所有声卡 / 应用均已实测。浏览器截图接口在当前环境不可用，未进行最终像素对照验收。后台页面也不能用于推断真实 OBS 的帧率。

CI 已提供 Windows / Linux 的自动检查流程，但在仓库发布前尚未由 GitHub Actions 实际运行。上播前请用自己的 OBS、采集来源与输出分辨率做短时间试播。

## 发布操作

使用 `dist/` 中的 ZIP 作为源码 Release 附件，标签建议为 `v0.1.0-beta.1`。压缩包根目录就是仓库内容。把该根目录文件上传到新仓库即可；不要上传个人开发工作目录。代码与文档已按 MIT 整理，第三方字体和代码保留原许可。

此整理过程没有创建远程仓库、推送提交、创建标签或发布 GitHub Release。
