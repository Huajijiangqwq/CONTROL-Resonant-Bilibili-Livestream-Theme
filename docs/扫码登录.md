# 哔哩哔哩扫码登录

在「主题编辑器 → 主题设置 → 弹幕接入」中选择真实接入，然后点「扫码登录」。也可以从直播预览或弹幕模拟器的真实接入设置打开。

1. 使用自己的哔哩哔哩 App 扫描二维码，在手机上确认登录。
2. 页面显示“登录成功，已在本机加密保存”后，输入房间号或链接，点击连接。
3. 下次启动直接连接，SESSDATA 输入框留空；无需反复复制。凭据过期或失效时重新扫码。

「主播身份码（暂未开放）」保留为禁用入口，目前不能使用身份码建立正式连接。

## 独立脚本

源码版可双击根目录的 `扫码登录哔哩哔哩.cmd`，需要 Node.js 24+。脚本优先连接当前桌面客户端的接入服务；没有运行服务时启动一个临时本机服务。登录完成后按 Ctrl+C 关闭临时服务，再启动桌面客户端。

指定接入服务端口：`node scripts/bilibili-login.js --port 8813`。这里填写弹幕接入服务端口，而不是预览页端口。

## 保存与清除

- 仅保存本次扫码取得的 SESSDATA，使用 Windows DPAPI 绑定当前 Windows 账户加密。
- 默认存放于 `%APPDATA%/Control Resonant/data/bilibili-session-credentials.enc`；桌面自定义测试配置使用对应配置的 `data` 目录，`CONTROL_DATA` 可指定该目录。
- 不输出明文凭据、不写入主题 JSON、浏览器存储或导出包，不向在线二维码服务上传数据。
- 手动填写 SESSDATA 仅供本次连接；手动内容优先于保存的登录。勾选“本次使用访客模式”可临时跳过保存的登录。
- “清除已保存登录”删除本机保存并断开当前网页接入，不等同于 Bilibili 账号的全设备注销。
- 断开直播间不会删除扫码保存；更换 Windows 账户后需重新扫码。

扫码使用 Bilibili 网页登录接口，后续接口变化可能需要更新适配；二维码过期可重新生成。真实登录只会在手机确认后完成，不会由程序自动确认。
