# 中文预设与术语

预设采用《控制》简体中文语境。这里的“原文”指游戏汉化后的中文文本，不是英文，也不是本项目重新翻译的台词。

| 名称 | 本项目用法 |
| --- | --- |
| 太古屋 | 替换误写的“旧屋”；包括示例用户名“太古屋来客” |
| 联邦控制局 | 机构全称；在上下文明确时使用“控制局” |
| 希斯 | 敌对共振现象名称 |
| 异化物 | 礼物档案主题所采用的游戏术语；不混写为“权能物” |
| 控制点、热线电话、北极星 | 沿用简体中文游戏用语 |

术语核对参考：[《控制》简体中文剧情名词说明](https://steamcommunity.com/sharedfiles/filedetails/?id=2218941954)、[包含简体中文游戏流程的图文记录](https://www.gamersky.com/handbook/201908/1213260.shtml)。简体与繁体本地化存在不同译名，本项目不混用。

`app/remedy-presets.js` 将预设分为：

- **游戏中文原文 · 任务标题**：少量简短的游戏 UI 原文，逐条附来源链接。当前使用任务标题，不将其说成角色对话。
- **日常弹幕 · 使用游戏术语**：本项目编写的模拟观众弹幕，沿用游戏术语，但不是游戏台词。

后续新增中文对话必须核对游戏字幕或可追溯的中文实机画面；仅有英文时不自行翻译并称其为“汉化原文”。不使用长篇游戏档案、完整台词脚本或未经核实的名句。游戏中文原文的权利仍属于原权利方，不纳入项目原创文档 / 素材的 CC 许可。

设置中的中文预设选择器会区分这两类内容。替换只更新发行包默认值，不覆盖用户已经保存的主题或自行编辑的消息。
