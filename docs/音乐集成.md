# 音乐识别、音频可视化与开源来源

本项目代码使用 GPT-6 Astra 生成，部分素材使用 image 生成。第三方项目单独署名；以下描述不表示它们的代码由本项目生成。

## 桌面版内置识别

客户端启动本地音乐皮肤服务，并默认使用 Windows SMTC（系统媒体传输控制）读取播放器主动上报的歌名、歌手、专辑、封面、播放状态及进度。无需单独运行歌曲服务；音乐皮肤中可以切换来源。

实现为本项目原创的 `app/windows-media.ps1` 与 `app/windows-media.js`，MIT。通过 Windows PowerShell / .NET Framework 的 WinRT 桥访问系统 API，没有复制上游 GetMusicStatus 组件，也没有捆绑其 CSCore、WindowsMediaController、Newtonsoft.Json、Java 或 UIAutomation 二进制。

- 仅识别接入系统媒体会话的播放器，不承诺所有网易云 / QQ 音乐版本均可用。若没有曲目信息，在播放器设置中开启系统媒体信息，或切换外部来源。
- 使用系统当前媒体会话；浏览器视频也可能成为当前会话。播放器未上报的封面或进度不会伪造。
- 不控制播放器播放 / 暂停，不自动录音，不上传曲目。只在本机服务与本机画面之间传递数据。
- 读取间隔约 750 ms；标题与封面可能异步变化，因此切歌后会短暂重新读取封面。
- 音频流纹仍使用本项目 WASAPI 捕获与 fft.js 分析，需用户主动开启；元信息和频谱是两条独立链路。

API 依据：[Microsoft GlobalSystemMediaTransportControlsSessionManager](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionmanager)。系统要求 Windows 10 1809+。

## now-playing-service 兼容模式

[Widdit/now-playing-service](https://github.com/Widdit/now-playing-service) 是 MIT 开源项目，版权为 Copyright (c) 2024 Widdit。核查版本为 `v2.2.0`；源代码核查提交：`2336c5fc6c57300bc7cf5fa85c7f273042bb86b1`，2026-09-22。

本项目已经集成其 `/query`、`/query/progress` HTTP 接口，读取歌曲、封面和进度。音乐皮肤 → 歌曲信息 →「自动下载并配置」，会先复用已运行或已安装的上游程序；没有安装时，从官方 GitHub 下载固定的 v2.2.0 安装器，校验完整 SHA-256 后安装并启动后端，将歌曲来源和本机地址自动保存。Windows 可能要求确认安装权限。后续使用外部来源时，客户端会自动接续已配置的服务。更广的平台识别由上游完成，平台选择在「打开 Now Playing 设置」中调整。

官方下载：[v2.2.0](https://github.com/Widdit/now-playing-service/releases/tag/v2.2.0)。安装器 SHA-256：`92529ff4425f98d8e7374dd358f5acfaf01ba9cc6782b76dbc49e0f5e30a72ab`。原作者 **Widdit**，MIT，版权与第三方声明保留在官方程序中。没有使用非官方镜像、修改上游安装器或代替其许可。下载失败可重试，也可手动安装后点击检查连接。默认地址 `http://127.0.0.1:9863`，已有自定义端口可手动填写。

上游包含独立后端、GetMusicStatus 等辅助程序，前端也单独维护。此发行包不捆绑它们的完整二进制；仅在点击自动配置时下载官方整合包。内置 SMTC 的支持范围与上游不同，仍可随时切回内置来源。下载缓存和安装记录保存在本机 `external-now-playing` 目录，不进入主题导出和源码发行包。

上游许可副本见 `licenses/now-playing-service-MIT.txt`。本项目没有修改或重新许可上游；参考了它将 SMTC 元信息与音频捕获分离的思路，适配器是独立实现。

## 常见问题

- **有歌名，流纹不动**：到音乐皮肤开启音频捕获，选对桌面或应用音源。
- **有频谱，没有歌名**：检查 SMTC 媒体会话，或切换外部服务。
- **外部服务没连接**：点击「自动下载并配置」检查连接；若使用非默认端口，请先填写正确的本机地址。安装被取消、网络失败和端口占用都会显示提示，可重试。
- **OBS 无法读取**：保持客户端或托盘服务运行，使用直播预览或音乐皮肤复制的当前本机地址。
