# 公开运行版与开发源码

桌面客户端面向实际直播，保留直播预览、音乐皮肤、主题编辑器、弹幕编辑器及使用帮助。直播预览保留发送一条测试消息的接入检查；编辑器中的消息预览、时间轴和曲线属于主题制作功能，继续提供。

## 公开桌面运行包

Windows 和 macOS 构建使用同一份运行文件策略，实际排除以下文件，而非仅隐藏入口：

- `app/monitor*`：独立组件监视、录制与配套音频时钟。
- `app/sc-compare.{html,css,js}`：旧 SC 档位对比工具。
- `app/normal.*`、`app/gift.*`、`app/levitation.*` 的 HTML、JS、CSS：独立时间轴实验页。
- `app/simulation-controls.{js,css}`：独立消息实验室的界面。
- `tests/`、`scripts/`、`.github/`：回归测试、构建和 CI 代码。

`simulation.html?embed=main` 和 `simulation.js` 继续保留：它们是直播页、组合弹幕区及独立消息实例共用的运行时。`*-notice-engine`、SC / 舰队 / 希斯效果模块及素材也继续保留。访问旧的独立 `simulation.html` 地址会返回直播预览。

运行包带有 `PUBLIC-RELEASE.json`。该标记使 URL 的 `dev=1` 和继承的 `CONTROL_DEV` 环境变量都无法开放开发控件。源码和运行包分别带有对应内容的 SHA-256 文件清单；两份归档的文件数本来就不同。

## 源码中的开发工具

源码 ZIP 保留全部开发页面和自动化测试，便于贡献者复现动画问题。正常的 `npm start`、`npm run preview` 和 `npm run start:server` 使用公开模式，开发页返回 404。

在源码目录运行：

```sh
npm run dev -- --port 18891
```

这个命令只启动预览服务，不自动连接直播间或捕获音频。开发服务可访问 `monitor.html`、`sc-compare.html` 等页面。主直播页和音乐皮肤中的额外演示控件还需在地址加入 `?dev=1`，例如 `http://127.0.0.1:18891/now-playing.html?dev=1`。公开服务器中仅加入这个参数无效。

开发服务由明确的启动参数或 `CONTROL_DEV=1` 开启，HTTP 请求不能更改此状态。普通用户无需启用开发模式即可调整音乐参数、制作主题或检查一条消息。

## 校验

`npm run check` 同时检查完整源码资源引用和经过剔除、HTML 清理后的公开文件集合，防止误删共享引擎。`npm test` 验证公开模式访问隔离、开发模式开关和内嵌消息渲染入口。构建脚本按同一文件集合生成 Windows、Mac 运行内容。

原开发工作目录和以前的发布 ZIP 不会因打包而被删除。个人凭据、草稿、运行设置和录制文件始终不进入公开或源码归档。
