# Beta 1 使用说明

**AI 生成说明：本项目代码使用 GPT-6 Astra 生成，部分素材使用 image 生成。**

日常使用从「直播预览」开始：选布局、接弹幕、复制 OBS 地址即可。音乐皮肤、消息模拟和组件监视面板可按需要单独使用。

## 1. 启动与退出

下载桌面包后，先解压整个文件夹，再双击 `ControlResonant.exe`。程序会启动本地服务并打开直播预览，无需另装 Node.js。首次启动会选择空闲端口，后续保留；请始终使用界面复制的地址。

关闭窗口会收起到系统托盘，让 OBS 继续显示。结束使用时，在托盘选择「退出并停止本地服务」。「关于与许可」可打开使用说明、数据目录和许可文件。

使用源码时，安装 Node.js 24+ 后运行根目录的 `启动全部服务.cmd`。默认页面端口为 8791，Bilibili 接入为 8793，音频为 8794，音乐为 8795。其他端口可使用 `npm run start:server -- --port 18891` 指定。

## 2. 直播预览：选择直播布局

右侧「直播布局」提供三种常用排版：

| 布局 | 适合的画面 | 消息展示 |
| --- | --- | --- |
| 完整主题 | 保留完整品牌区和右侧通讯记录 | 各类消息在弹幕区内展示 |
| 游戏优先 | 增大游戏内容占比 | 保留较紧凑的主题与消息区域 |
| 全屏分区 | 游戏铺满画面 | 普通弹幕、SC、礼物、上舰提示分区展示 |

在「画面设置」填写主播名称和直播标题；标题白框随文字长度调整。全屏分区默认隐藏直播标题（备注），需要时勾选「全屏分区显示直播标题（备注）」。

游戏示例只用于预览，实际游戏请在 OBS 中单独采集。先关闭「显示游戏示例画面」，再使用「纯画面预览」检查输出。主直播页可选择开启 Now Playing，音乐设置在侧栏「音乐皮肤」中调整。

切换布局会保留当前消息和计时。手动添加的 OBS 游戏采集需按界面显示的位置、尺寸调整；也可为不同布局分别保存 OBS 场景。

## 3. 弹幕接入：扫码登录与连接房间

「弹幕接入」位于直播预览右侧顶部，也可在「消息模拟」中操作。

1. 将消息来源切换到 Bilibili 直播间。
2. 点击「扫码登录」，使用哔哩哔哩 App 扫码并确认。确认过程由你在 App 中完成。
3. 填写房间号或直播间链接，点击连接。
4. 查看连接状态，并用实际直播间消息确认普通弹幕、礼物、SC、上舰消息是否到达。

扫码后自动获取登录信息，并在当前 Windows 账户下加密保存；重启后无需重复填写 SESSDATA。可清除本机保存的登录。手动填写 SESSDATA 仅用于本次连接，不会自动保存；不要填写整段 Cookie。

也可选择访客模式先尝试连接，但用户名等内容可能被平台打码。主播身份码接入目前标注为「暂未开放」。本接入采用网页消息协议，平台鉴权、网络或风控变化可能影响可用性。详见 [扫码登录说明](扫码登录.md)。

## 4. 放入 OBS

日常使用已有布局不需要打开编辑器，也不要求连接 OBS WebSocket。

1. 在直播预览点击「复制 OBS 地址」。
2. 在 OBS 场景中添加「浏览器」来源，粘贴地址；完整主题设置为 **1920 × 1080**。
3. 添加自己的游戏采集，放在主题浏览器源下方。
4. 按直播预览显示的位置和尺寸调整游戏采集。全屏分区的游戏区域为 1920 × 1080。
5. 检查预览效果，再自行开始直播或录制。程序不会替你开始或停止直播、录制。

单独使用音乐皮肤时，从音乐页面复制浏览器源地址，尺寸为 **1920 × 560**。添加后可在 OBS 内等比缩放到需要的大小。

请使用 `http://127.0.0.1:…` 本地服务地址，不要勾选「本地文件」或使用 `file://`。运行 OBS 期间保留客户端或托盘服务；重开客户端后若分配地址改变，请更新浏览器源 URL。

## 5. 音乐皮肤与音频可视化

侧栏「音乐皮肤」负责歌名、歌手、封面、播放进度和希斯流纹的显示。可独立作为 OBS 来源，也可在直播预览中开启内嵌展示。

### 获取当前歌曲

桌面版默认使用 Windows 媒体会话（SMTC），读取播放器提供的歌曲信息。先在播放器中播放歌曲，再观察页面是否识别；播放器需支持系统媒体控制。

需要其他平台适配时，将歌曲来源切换到「外部 now-playing-service」，点击「自动下载并配置」。程序从原作者官方 GitHub 下载并校验安装器，安装后启动服务并保存连接；安装时可能需要 Windows 许可确认。已安装或已运行的服务会优先复用，也可手动填写本地服务地址，默认 `http://127.0.0.1:9863`。

**外部歌曲服务：** [now-playing-service](https://github.com/Widdit/now-playing-service)，原作者 **[Widdit](https://github.com/Widdit)**，采用 **MIT** 许可。本项目未随包捆绑其安装器或完整后端；详细来源与集成范围见 [音乐集成](音乐集成.md)。

### 让流纹跟随音乐

歌曲识别和音频捕获是两项功能。歌名正常显示后，还需在音频设置开启桌面音频或指定应用的捕获，流纹才会跟随真实声音变化。

可调整灵敏度、起跳与回落，以及页面开放的流纹和录像质感参数。换输出设备后没有反应时，重新选择音源或停止后再开启。合成演示不播放声音，也不代表音频捕获成功。

帧率可选 60 FPS、30 FPS 或自定义上限；自定义最高 240。实际帧率还受 OBS、显示器、显卡及效果数量影响，性能不足时先选 30 FPS 或降低效果强度。

## 6. 消息模拟与组件监视面板

没有接入直播间时，可在「消息模拟」选择普通弹幕、SC、礼物、舰长 / 提督 / 总督，填写内容后发送，检查排版与动画。

SC 有独立倒计时，多个有效 SC 在分区布局中切换展示；上舰、礼物的停留时间可按界面设置。测试完成后清空消息，再切回真实弹幕来源。

「组件监视面板」提供 14 个独立预览页，方便分别检查、录制各类提示或特效。可设置内容、位置、效果与入退场时间，输出 1920 × 1080 纯画面；录制方法见面板内的录制说明。测试消息用于本地预览，不会发送到 Bilibili 直播间。

## 7. 保存配置、更新与备份

界面配置保存在本机。桌面版服务数据位于应用数据目录的 `data/`，浏览器设置位于同一应用用户目录；从「关于与许可 → 打开数据文件夹」查看。更新前退出客户端，保留该数据目录，再使用新版本程序。

| 内容 | 保存方式 |
| --- | --- |
| 直播布局与页面设置 | 本机页面存储；不同浏览器、端口或客户端配置互不等同 |
| 扫码登录 | 当前 Windows 账户的加密凭据；不随主题导出 |
| 音频、歌曲服务配置 | `audio-settings.json`、`now-playing-settings.json` |
| 自动配置的外部音乐服务 | `external-now-playing/` 内的安装及管理信息 |
| 主题草稿、发布快照 | 页面草稿与 `theme-projects/`、`theme-live/` |

个人设置、登录凭据、安装缓存和日志均不应上传到开源仓库，也不会进入源码打包结果。主题迁移使用 JSON 导入导出；私有素材需要自行确认后再分享。

## 8. 常见问题

- **OBS 空白**：先确认客户端直播预览能打开，本地服务正在运行；检查浏览器源 URL、端口和尺寸，关闭游戏示例，确认来源没有被隐藏或挡住。必要时启用 OBS 浏览器源硬件加速并重启 OBS。
- **没有收到弹幕**：检查房间号、消息来源和连接状态；登录过期时重新扫码。连接成功不等于平台一定返回所有消息。
- **有歌名但流纹不动**：检查是否已开启音频捕获、选择了正确的音源，以及该音源是否正在发声。
- **外部歌曲服务安装失败**：确认网络能访问 GitHub；如取消了 Windows 安装确认，可重新点击「自动下载并配置」，也可从原作者发布页手动安装后填写地址。
- **端口被占用**：关闭自己的旧副本，或选择其他端口。启动程序不会强制结束占用端口的其他软件。
- **特效卡顿**：降低帧率或效果强度，减少同时显示的高强度消息，按实际 OBS 输出尺寸检查。
- **需要反馈问题**：记录操作步骤、截图、版本和错误提示，先删除其中的账号凭据或私人信息；欢迎反馈 bug 和建议。

## 9. 【实验功能】主题编辑器与弹幕编辑器

**目前处在极早版本，存在诸多 bug 和问题。** 两个编辑器位于客户端侧栏最下面，适合尝试自定义；使用前备份重要主题。日常使用预设主题、接弹幕、播放音乐和输出 OBS 无需经过编辑器。

### 主题编辑器：调整整个场景

从「文件 / 从现有布局开始」选择完整主题、游戏优先、全屏分区或已有自定义。左侧添加元素，右侧调整位置、宽高、图层、排版及已开放的特效属性。游戏窗口是示例，不是真实游戏采集。

边框通过独立部件绘制，可调整长宽比例；文字通过字号和排版宽度调整。主播名称、直播标题（备注）、直播状态已拆为独立素材，各自设置位置、字号与显隐，内容与主题设置同步。旧主题的「主播与标题」图层可点击「拆分为独立组件」，支持撤销。全屏分区的备注图层默认隐藏，点图层眼睛可恢复。

「组合弹幕区」让普通弹幕、SC、礼物、上舰提示共享区域、顺序和上下文；「独立消息图层」可将它们分别摆放。是否属于弹幕区取决于组件归属和展示方式；已有图层可以复制成多个实例。

### 弹幕编辑器：调整消息区域内部

用于调整消息区域内的字体、部件、间距和特效。编辑上舰或 SC 时，注意当前修改的是组合区内的样式，还是独立消息实例。

底部发送预览与时间轴用于观察入场、停留、退场。关键帧只适用于已开放的属性，并非所有内部变量都能编辑。重要修改前在「文件」中导出主题 JSON；不要在多个页面同时编辑同一份草稿。

### 实验性的 OBS 一键接入与同步

在 OBS 开启 WebSocket 服务，编辑器打开「应用 / OBS」，连接本机 OBS，选择游戏采集来源，创建主题场景或绑定已有主题浏览器源。标准 Windows 配置可自动读取，便携版可手动填写端口和密码。

绑定后修改布局会同步主题与游戏采集位置，通常不需要刷新来源。游戏依然由 OBS 采集；网页特效不能直接扭曲游戏像素。首次绑定可能更新来源 URL；服务重启后需恢复绑定，换场景集合会停止旧绑定。每个场景同一时间只由一个编辑页面写入；程序不会开始、停止直播或录制，也不会自动切换节目场景。
