# 本地开源字体

这些字体随皮肤本地提供，不依赖 Google Fonts 的在线服务。原始字体转为 WOFF2，未删减字符；版权及 SIL Open Font License 文本与字体一起保留。

| 字体 | 用途 | 官方来源 |
| --- | --- | --- |
| Anton | 拉丁字母标题，窄体粗黑风格 | https://github.com/google/fonts/tree/main/ofl/anton |
| Roboto Condensed | 西里尔字母、希腊字母 | https://github.com/google/fonts/tree/main/ofl/robotocondensed |
| Noto Sans CJK SC Black | 简繁中文、日文、韩文；共享 CJK 字符集 | https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese |
| Noto Sans Arabic | 阿拉伯文及该字体包含的扩展字符 | https://github.com/google/fonts/tree/main/ofl/notosansarabic |
| Noto Sans Hebrew | 希伯来文 | https://github.com/google/fonts/tree/main/ofl/notosanshebrew |
| Noto Sans Devanagari | 印地文等天城文 | https://github.com/google/fonts/tree/main/ofl/notosansdevanagari |
| Noto Sans Thai | 泰文 | https://github.com/google/fonts/tree/main/ofl/notosansthai |

字体合计约 13.4 MB，按曲目需要加载。CJK 使用 SC 地区字形，包含日文假名和韩文字符，不宣称每个地区汉字都使用专门的地区字形。
