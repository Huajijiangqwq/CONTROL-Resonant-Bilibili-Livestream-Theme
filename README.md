**Beta 1 · `0.1.0-beta.1` · Windows 桌面客户端 · 代码 MIT / 文档与原创素材 CC BY 4.0**

以《Control / 控制》的视觉语言为灵感，为 Bilibili 直播制作的 OBS 主题。选择直播布局、扫码连接直播间，即可展示普通弹幕、SC、礼物与三级上舰提示；另有独立音乐皮肤、音频可视化及消息测试功能。

这是独立的爱好者项目，与 Remedy Entertainment、Bilibili、OBS Project 无隶属或合作关系。本包包含可运行的源码，不需要 Codex，也不需要在线构建服务。

## 能做什么

- **直播预览**：完整主题、游戏优先、全屏分区三种排版；主播名称、直播标题、直播计时及中英文 Logo。全屏分区的标题备注默认隐藏，可按需开启。
- **Bilibili 接入**：填写房间号或链接，接收普通弹幕、礼物、SC、上舰消息；支持扫码登录并在当前 Windows 账户下加密保存，重启无需重填。
- **消息特效**：不同档位 SC、舰长 / 提督 / 总督提示、礼物档案与普通弹幕动画；可设置停留时间，分区布局支持有效 SC 轮播。
- **OBS 输出**：复制本地浏览器源地址即可使用透明主题，游戏采集放在下方；日常使用预设布局无需经过编辑器。
- **音乐皮肤**：内置 Windows 歌曲识别，可自动下载并配置原作者的外部 now-playing-service；多语言字体、长标题排版、VHS 质感与真实音频驱动的希斯流纹。
- **消息模拟**：本地发送四类测试消息，检查排版与入退场；不向真实直播间发送内容。
- **本地保存**：界面和服务设置保存在本机，个人数据不进入源码包。
- **组件监视面板**：14 个独立预览页，单独调整内容、位置、特效和入退场时间；输出 1920 × 1080 纯画面，用于自行录制和后期合成。访问本地服务的 `monitor.html`，录制说明见 `monitor-guide.html`。

## 桌面版快速开始（Windows）

1. 下载 `ControlResonant-0.1.0-beta.1-win-x64.zip`，解压整个文件夹。
2. 双击 **`ControlResonant.exe`**。客户端包含运行环境，无需另装 Node.js 或 .NET SDK。
3. 启动后直接进入**直播预览**。右侧第一组是“弹幕接入”，选择 Bilibili 直播间后即可扫码登录、填写房间号并连接。
4. OBS 地址以客户端显示 / 复制的地址为准。首次启动自动选择空闲端口组，后续保留这组端口。
5. 关闭主窗口会收起到托盘，让 OBS 继续显示。结束使用时，在托盘选择“退出并停止本地服务”。

支持 Windows 10 1809+ / Windows 11 x64；按应用捕获音频建议 Windows 11。客户端不会自动开始直播、录制或音频捕获。便携包未做代码签名，版本与完整性可通过随包 SHA-256 校验。

用户数据保存在系统应用数据目录，可从“关于与许可”打开。设置、发布主题与浏览器草稿不写入安装目录；更新时关闭客户端，再换用新版本程序。旧浏览器中的主题需先导出 JSON，再在客户端导入。

### 从源码启动

安装 Node.js 24+ 和 npm。在项目目录执行 `npm install`，然后 `npm run build:audio`、`npm start`。仅使用网页服务也可运行 `启动全部服务.cmd`，无需安装 Electron。不同端口的浏览器草稿彼此独立；扫码登录默认共用当前 Windows 账户的加密凭据，可用 `CONTROL_DATA` 指定独立目录。

## 放入 OBS

1. 直播预览中点击「复制 OBS 地址」。
2. OBS 添加「浏览器」来源，粘贴地址，宽高设为 **1920 × 1080**。
3. 关闭主题中的游戏示例，将自己的游戏采集放在主题来源下方，按页面提示调整位置与尺寸。
4. 切换布局后检查游戏采集位置，也可分别保存 OBS 场景。准备好后自行开始直播或录制。

这个流程不需要 OBS WebSocket。单独使用音乐皮肤时，从音乐页复制来源地址，尺寸设为 **1920 × 560**。运行期间保持客户端或托盘服务在线；不要用 Windows 文件路径作为浏览器源地址。

详细步骤见 [使用说明](docs/使用说明.md)。

## Bilibili 与音乐

在模拟器或主直播页选择真实接入，填写房间号即可尝试连接。访客连接可能显示打码用户名；需要时填写自己的 SESSDATA。点击“扫码登录”后使用哔哩哔哩 App 扫码确认，会自动获取 SESSDATA 并在当前 Windows 账户下加密保存；重启后留空凭据即可使用。手动填写仅用于本次连接。身份码接入标注为“暂未开放”。详见 [扫码登录](docs/扫码登录.md)。

该接入采用网页消息协议，**不是 Bilibili 官方开放平台应用**。平台接口、风控或鉴权变化可能导致连接失败；本项目不承诺所有房间和账户都可用。

桌面版默认通过 **Windows SMTC** 读取播放器上报的歌名、封面和进度，不需要另开歌曲服务。对未接入 SMTC 的播放器，可在音乐皮肤中选择“外部 now-playing-service”，点击「自动下载并配置」，安装并连接原作者 [Widdit/now-playing-service](https://github.com/Widdit/now-playing-service)（MIT），默认地址 `http://127.0.0.1:9863`。未捆绑其完整后端或安装器；具体集成范围、核查版本及限制见 [音乐集成说明](docs/音乐集成.md)。频谱仍由本项目独立捕获桌面 / 应用音频；读取歌名不等于开启音频捕获。

## 开发与校验

```sh
npm start                     # 打开桌面客户端（先 npm install）
npm run start:server          # 无桌面窗口，前台启动全部服务
npm run preview               # 仅编辑器预览，不启动直播/音频服务
npm run start:server -- --port 18891      # 独立端口组 18891 / 18893 / 18894 / 18895
npm run check                 # 语法、资源引用与发布清洁检查
npm test                      # 核心逻辑、OBS 模拟与本地服务检查
npm run package               # 生成干净源码 ZIP、文件清单、SHA-256
npm run build:desktop         # 验证并打包 Windows x64 桌面版
npm run stop                  # 停止本目录启动的服务
```

macOS / Linux 可运行纯预览与逻辑测试；音频捕获、自动读取 OBS Windows 配置和完整启动流程目前仅面向 Windows。Beta 1 仍采用无构建的原生 JS / Canvas / WebGL 架构，部分早期模块较紧凑，后续会渐进整理。

```text
desktop/      桌面外壳、托盘与本地服务管理
app/          正式页面、编辑器、特效、消息与本地服务
app/assets/   主题素材与第三方资源（来源见素材清单）
scripts/      启停、编译、检查与打包
tests/        保留的发布回归测试（无历史试验页面）
docs/         使用、架构、许可和发布说明
licenses/     第三方许可
```

桌面版的浏览器草稿、设置与主题发布数据位于独立用户数据目录。直接运行网页启动脚本时，数据仍保存在 `app/` 下对应目录，日志及启动身份保存在 `.runtime/`。这些均已被 Git 与打包脚本排除。迁移前请先导出主题 JSON。

## 已知限制

- WebGL 2 和显卡硬件加速影响效果及帧率；60 FPS 是帧率上限，不是所有设备上的性能保证。
- 多个高强度 SC / 多个音乐实例会增加 GPU 消耗；先用 OBS 实测再上播。
- 主题文件与本地服务面向个人桌面使用，不是面向互联网部署的多人服务。不要公开端口或公开包含私人素材的主题文件。

## 【实验功能】主题编辑器与弹幕编辑器

**目前处在极早版本，存在诸多 bug 和问题。** 两个编辑器统一位于客户端侧栏最下面。使用预设直播主题无需经过编辑器；尝试自定义前请导出重要主题 JSON 备份。

- **主题编辑器**：从现有布局开始，添加或复制组件，调整位置、比例、图层、分组与开放的特效参数。主播名称、直播标题（备注）、直播状态可独立排版；旧的「主播与标题」层支持拆分。
- **弹幕编辑器**：调整消息区域内部的字体、部件和效果。组合弹幕区共享消息上下文，独立消息图层可分别摆放；已有图层支持多实例。
- **动画编辑**：时间轴支持已开放属性的关键帧与曲线，不是完整的 AE 替代品。
- **OBS 一键接入与布局同步**：开启 OBS WebSocket 后，通过「应用 / OBS」创建或绑定场景。连接后同步主题和游戏采集位置，通常无需刷新；服务重启或场景集合变化后需恢复绑定。同一场景同时只由一个编辑页面写入。

游戏依然由 OBS 采集，网页特效不能直接扭曲游戏画面。程序不会开始、停止直播或录制，也不会自动切换节目场景。具体操作、快捷键及限制集中在 [使用说明](docs/使用说明.md) 最后的实验功能章节。
